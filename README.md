### 🚗💻 Online Car Rental System

An interactive and responsive web application that allows users to **book, rent, and manage cars online**. This system is built using **HTML**, **CSS**, **JavaScript**, **PHP**, and **MySQL**, providing both customers and admins a seamless experience for handling car rental services.

---
## 🚀 Key Features

### 👨‍💼 User Panel:
- 🔍 Browse available cars by brand/type
- 📅 Book cars for specific dates
- 💲 View rental pricing and car details
- ✉️ Contact form for inquiries

### 🔐 Admin Panel:
- ✅ Admin login system
- 🚘 Add/Edit/Delete car listings
- 📆 Manage bookings & availability
- 📊 Dashboard with car status & booking history
